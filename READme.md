# Protótipo do Sistema de Estacionamento

Protótipo desenvolvido em Python para demonstrar os requisitos RQ01, RQ02 e RQ03.

## Requisitos implementados

- RQ01: detecção de vagas ocupadas/livres e reconhecimento de placas.
- RQ02: identificação de veículos autorizados e não autorizados.
- RQ03: identificação e registro de ocupações indevidas em vagas reservadas.

## Execução

Execute o arquivo principal com:

```bash
python main.py
